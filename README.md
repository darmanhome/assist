# DarmanHome

ابزار آنلاین ارزیابی و برنامه‌ریزی درمانی، ویژه‌ی متخصصین توان‌بخشی.

این ابزار به متخصصان کمک می‌کند تا بر اساس اطلاعات بیمار، برنامه‌ی
درمانی، تمرینات، و پروتکل مناسب را به‌صورت سریع و ساختاریافته تهیه کنند.

## امکانات
- ارزیابی وضعیت بیمار بر اساس تشخیص
- تولید خودکار برنامه‌ی تمرینی و توصیه‌های درمانی
- رابط کاربری ساده و سریع، قابل استفاده روی موبایل

تماس: darmanhome (پروژه‌ی شخصی/آزمایشی)
